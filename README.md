# Radioamatore – studio

Materiale di studio per la patente di radioamatore (esonero parziale), By Chitano Antonio.

- `index.html` – Bandplan HF spiegato con 20 codici visivi e di studio (v4), con lettore audio fisso: si legge e si ascolta insieme
- `dispensa.html` – testo completo della Dispensa Regolamentazione Radioamatore v7 con lettore audio fisso (19 capitoli MP3; il file unico in 2 parti è in download)
- `download.html` – dispensa v7 e Super v4 in PDF e DOCX, Bandplan in PDF

Sito: https://antonio1963.github.io/radioamatore-studio/
